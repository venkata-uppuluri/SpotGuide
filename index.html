Complete outage. All users impacted. No workaround.

⏱️ Response: 1 business day

ThoughtSpot Agents

ThoughtSpot’s AI agents bring intelligence directly into your analytics workflow. Each agent is purpose-built for a different persona — helping you get answers, build content, and take action faster without needing to write code or SQL.

🤖 What is a ThoughtSpot Agent? ThoughtSpot Agents are AI-powered assistants embedded in the platform. They understand your data, your questions, and your context — acting on your behalf to surface insights faster. From conversational analytics to formula writing and semantic modelling, each agent is purpose-built for a specific job.
🔍
Everyone Conversational AI

Spotter

Your conversational AI analyst. Ask questions in plain English and get instant charts, tables, and narrative answers from your live data — no SQL or code required. Spotter works against your ThoughtSpot semantic model to deliver trusted, governed results.

📌 Best for: Business users, analysts — anyone asking data questions
📌 Powered by: Your semantic model — data team sets it up, everyone benefits
Spotter Resource Hub →

Developer · Analyst

SpotterCode

AI-assisted code generation for ThoughtSpot. SpotterCode helps developers and data engineers write formulas, TML, and analytical expressions faster — with intelligent suggestions grounded in your semantic model and context.

📌 Best for: Developers and analysts building content in ThoughtSpot
📌 Helps with: Formulas, TML authoring, and analytical expressions
SpotterCode Docs →

Admin · Data

SpotterModel

AI-powered semantic modelling. SpotterModel helps data teams build and enrich ThoughtSpot’s semantic model faster — suggesting column descriptions, relationships, and synonyms so Spotter can answer questions more accurately across your organisation.

📌 Best for: Admins and data engineers building the semantic layer
📌 Impact: Better Spotter answers for all end-users downstream
SpotterModel Docs →

Everyone

SpotterViz

AI-generated visualisations. SpotterViz automatically selects the best chart type for your data and question, then builds and formats it — so you spend less time configuring visuals and more time acting on insights.

📌 Best for: Anyone who wants polished charts without manual configuration
📌 Works with: Spotter queries and existing Liveboards
